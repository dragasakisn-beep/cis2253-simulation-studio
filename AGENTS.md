# CIS2253 — Cyber Ethics Simulation Studio

## Development standard
- Correct project: CIS2253 Cyber Ethics Simulation Studio, not CIS3205 Cyber Compliance Lab.
- Requirements: four weeks, eight original branching scenarios, a minimum 45-minute substantive activity plan per session (target 55 minutes), Spinello 8th edition (2026), student evidence review, ethical reasoning, chronological decisions, instructor-gated modules, local progress and printable participation reports.
- Treat approved designs and assets as requirements. Never substitute photographs from individual lab scenarios for a dedicated homepage banner. Approved homepage asset: assets/photography/cis2253-ethics-hero.webp.
- Keep the application behavior, case data, saved progress, release hashes and participation report generation intact during visual-only enhancements.
- Make focused modifications. Use assets/cis2253-theme.css for visual refinements rather than modifying the existing embedded storyboards.
- Validate by running the automated checks and the browser smoke test; inspect desktop/mobile screenshots and verify the printable report after application-code changes. Never claim live deployment from a successful commit alone.
- If changes cannot be verified, state the limitation precisely. Avoid repeated approvals and minimize commentary.
- Never store real student records, release-code plaintext or other secrets in this public repository.
